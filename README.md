If you were just checking the output of one function which is just one piece of a program, a unit test would be more appropriate since there is no need to test the whole program flow when just focusing on one function.
3. Navigation mode analyzes a web page immediately after its initial load and providdes overall performance metrics for the page-load lifecycle. Snapshot mode analyzes a web page in its exact current state at a specific moment without reloading it which is best for uncovering accessibility flaws within dynamic states or hidden UI elements.
4. Every time the set data function runs, a brand-new style tag is created which results in reddundant style blocks being parsed and kept in memory. This can be replaced with a single static component stylesheet which would improve page rendering and decrease overall DOM size. The repo currently delivers JS and CSS code text raw directly to the user's browser context where a minifier tool could be used to compress syntax and strip spaces decreasing the network payload size and reducing initial download times, maximizing overall performance score. Lastly, the web application maps direct URLs straight into uncompressed image tags where compressing them would accelerate image loading speeds and improve the site's Largest Contentful Paint (LCP) metric.
